# Gold & Foreign Exchange Tracking Application

## Overview

This project is a real-time financial data tracking application that retrieves gold and foreign exchange rates from an external API and presents them in a structured and user-friendly interface.

The application focuses on real-time data processing, dynamic rendering, and responsive design principles.

## Key Features

- Real-time gold price tracking
- Live foreign exchange rates (USD, EUR, etc.)
- External API integration
- Dynamic DOM updates
- Data processing and formatting
- Responsive user interface

## Technical Details

The application fetches live market data using asynchronous HTTP requests and processes the response to display structured financial information on the frontend.

It demonstrates:
- API integration
- Asynchronous JavaScript (Fetch / Axios)
- JSON data handling
- Dynamic UI updates
- Modular and maintainable code structure

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- REST API integration
